# Statistical Analysis in R

## Questions

The coursework analysis considers household food expenditure and podcast listening. It combines data checks and exploratory visualisation with regression models, interaction terms, confidence intervals, and model-based comparisons.

## Code

[`coursework_regression_and_visualisation.R`](r/coursework_regression_and_visualisation.R) contains the extracted R code from two assessment sections. The script expects the CSV inputs named in [`../../data/README.md`](../../data/README.md); those inputs are not included.

This is team coursework. The original assessment declaration records Gemini and ChatGPT assistance for code debugging, example approaches, and language editing.
