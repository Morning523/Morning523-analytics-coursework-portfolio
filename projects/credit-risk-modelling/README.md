# Credit Risk Modelling

## Case question

How can a coursework credit-application dataset be prepared and used to compare a baseline neural network with an optimised model, including performance across pre-defined risk segments?

## Code

[`credit_application_neural_network.ipynb`](notebooks/credit_application_neural_network.ipynb) covers feature preparation, train/validation/test splitting, clustering-based segments, PyTorch model training, evaluation metrics, and visual comparisons.

## Data and teamwork

This is a team coursework case. The referenced loan sample is not included because its redistribution terms were not verified. Results are not independently reproduced in this repository; no individual applicant records are published.
