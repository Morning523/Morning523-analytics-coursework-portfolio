# Underground Temperature Statistics

## Case question

Does platform temperature differ meaningfully between London Underground lines, and specifically between the Bakerloo and Central lines, both across all months and in summer months only?

## Code

[`r/london_underground_temperature_analysis.R`](r/london_underground_temperature_analysis.R) covers data quality checks, cleaning (implausible temperature values, sub-surface lines excluded from the line comparison), descriptive statistics by line, distribution visualisation, and two-sample t-tests comparing Bakerloo vs Central temperatures overall and in summer months.
